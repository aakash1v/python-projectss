# 🐍 My Small Python Projects

This repository contains my personal implementations of the 81 "easy practice programs" from the excellent book **"The Big Book of Small Python Projects" by Al Sweigart**.

This is a "learning-in-public" project. My goal is to work through each project to sharpen my Python fundamentals, practice problem-solving, and build a consistent coding habit.

You can find the book here: [nostarch.com/big-book-small-python-projects](https://nostarch.com/big-book-small-python-projects)

## 🚀 How to Run These Projects

Most projects are self-contained `.py` scripts.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/](https://github.com/)[your-github-username]/[your-repo-name].git
    ```
2.  **Navigate to a project directory:**
    ```bash
    cd [your-repo-name]/[project-name]/
    ```
3.  **Run the Python script:**
    ```bash
    python [project_file_name].py
    ```
